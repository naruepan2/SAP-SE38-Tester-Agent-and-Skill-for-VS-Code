# Roadmap

Potential future work should preserve the current read-only and evidence-first architecture.

- Validate the package against additional real SAP object types and systems.
- Add project templates supplied by actual delivery teams.
- Add automated linting for Agent, Skill, references, and template metadata.
- Add benchmark cases for root resolution, CDS tree normalization, field lineage, DCL/AMDP companions, and human-assistance behavior.
- Keep runtime execution and business-data validation in a separate approved testing workflow.
