# Defect Pattern Library

Review evidence for input overwrite, missing validation, unbounded reads, unsafe FOR ALL ENTRIES, incorrect lookup/key use, duplicate/fan-out, wrong output table, stale state, exception masking, misleading success message, arithmetic/date/currency errors, authorization observations, and performance amplification.

AUTHORITY-CHECK is optional unless requirements or sensitive operations prove it mandatory. Otherwise report as an informational security observation, not an automatic defect.
