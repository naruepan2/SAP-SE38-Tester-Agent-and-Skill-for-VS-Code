# CDS Dependency Analyzer
Use SAP ADT Dependency Analyzer or verified equivalent as a core structural method for CDS. Detect tree, graph, complexity, used-column and graph-export capabilities. If absent, use source parsing plus repository dependency search and state that the Analyzer was not executed.
Sequence: resolve/fingerprint root; read root source/fields; retrieve graph; retrieve complexity/used columns; normalize occurrences into canonical nodes/unique edges; preserve structural SELECT/UNION nodes; rank by proximity, custom logic, complexity, fan-in/fan-out, transformations and critical fields; drill down selected paths; read prioritized sources; resolve table functions to AMDP; add DCL/BDEF/service/UI/configuration companions; close gaps.
Complexity guides priority, not defect claims. Graph shows structure; source supplies aliases, calculations, annotations and semantics. Corroborate critical edges where possible. Report method, nodes/edges/depth, critical-path/field/branch coverage, AMDP/DCL coverage, unresolved nodes and stop reason.
