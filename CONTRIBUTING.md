# Contributing

1. Keep the Agent orchestration-only.
2. Put detailed rules in one authoritative reference.
3. Load specialist references only when triggered.
4. Preserve strict read-only behavior and no-guessing rules.
5. Do not duplicate full source or raw tool output across registries.
6. Add project templates through `template.yaml` and a referenced Markdown file.
7. Validate Markdown fences, YAML metadata, relative paths, duplicate IDs/aliases, and template immutability.
8. Update `CHANGELOG.md`, `VERSION`, and release notes for every published version.
