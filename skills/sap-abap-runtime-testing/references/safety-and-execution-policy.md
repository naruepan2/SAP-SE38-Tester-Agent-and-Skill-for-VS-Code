# Safety and Execution Policy

Runtime execution requires explicit user approval for the exact system, client, target, scenario, inputs, and operation. General approval to analyze source is not execution consent.

Prohibit source changes, activation, transports, posting, updates, commits, configuration changes, job scheduling, destructive cleanup, and unknown-side-effect tools. Prefer disposable/test data and non-production systems. If a scenario may affect persistent data, stop and create a manual test handoff.
