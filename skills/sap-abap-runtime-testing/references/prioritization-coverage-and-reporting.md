# Prioritization, Coverage, and Reporting

Prioritize by confirmed impact, reproducibility, affected scope, data-integrity risk, runtime failure, and user harm. Separate confirmed defects, probable causes, observations, and unverified hypotheses.

Report scenario coverage, executed/not-executed/blocked cases, evidence completeness, critical path coverage, limitations, and one completion status: `RUNTIME_COMPLETE`, `RUNTIME_COMPLETE_WITH_LIMITATIONS`, `RUNTIME_PARTIAL`, `HANDOFF_ONLY`, or `REPORT_VALIDATION_FAILED`.
