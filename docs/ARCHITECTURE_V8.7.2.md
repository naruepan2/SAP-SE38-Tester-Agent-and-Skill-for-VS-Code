# V8.7.2 Architecture

Runtime prompts are layered:
- Agent: immutable safety and orchestration.
- Skill: trigger-based reference router.
- Always-on interaction core: concise collaboration/no-guessing rules.
- Question patterns: loaded only when a question is necessary.
- Tool phases: raw artifacts remain external; normalized evidence pointers enter state; only critical evidence is promoted.
- Completed low-value detail is evicted from active context but remains traceable by fingerprint and evidence ID.
- Template discovery reads metadata only and loads one selected body.

No analytical capability is removed. Compaction changes where and when detail is loaded, not which rules or evidence are available.
